# LLM-Wiki

Example of a LLM-Wiki implemented with the help of SWE 1.6 agent (Windsurf)<br>
This implementation follows Andrej Karpathy guidelines on [LLM-Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)

Raw sources used to build the Wiki are web pages about diet approaches downloaded in .md files using Obsidian Web Clipper
